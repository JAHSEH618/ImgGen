# 📧 网易企业邮箱下载工具 - 使用指南

**专为非技术人员设计，简单易用，无需编程知识！**

---

## ⚡ 快速开始（3步完成）

### 第1步：准备工作

确保您的电脑已安装 Python 3：

- **Windows 用户**: 访问 https://www.python.org/downloads/ 下载安装
- **Mac 用户**: 电脑通常已自带 Python 3
- **如何检查**: 打开终端/命令提示符，输入 `python3 --version`

### 第2步：启动程序

根据您的操作系统选择：

**Windows 用户:**
- 双击运行 `启动邮件下载工具.bat`

**Mac 用户:**
- 双击运行 `启动邮件下载工具.command`
- 首次运行可能需要右键点击，选择"打开"

**Linux 用户:**
- 在终端中运行 `./启动邮件下载工具.sh`

### 第3步：按照向导操作

程序会问您几个简单的问题：

1. ✉️ **输入邮箱账号** - 如：zhangsan@company.com
2. 🔑 **输入密码或授权码** - 推荐使用授权码（更安全）
3. 💾 **选择保存位置** - 邮件将保存到哪里
4. 📁 **选择下载内容** - 收件箱、已发送，还是两者都要
5. ⚙️ **高级选项** - 是否全部下载、是否断点续传等

回答完这些问题后，程序会自动开始下载！

---

## 🔐 如何获取授权码（推荐使用）

使用授权码比直接使用密码更安全：

1. 登录网易企业邮箱网页版
2. 点击右上角 **设置** 图标
3. 进入 **安全** 选项
4. 找到 **客户端授权密码**
5. 点击 **生成新授权码**
6. 复制授权码，在程序中使用

## 💡 常见问题解答

### Q1: 我不懂编程，能用这个工具吗？

**A:** 完全可以！这个工具专门为非技术人员设计，只需要：
1. 双击运行启动文件
2. 回答几个简单问题
3. 等待下载完成

不需要任何编程知识！

### Q2: 下载需要多长时间？

**A:** 取决于邮件数量：
- 100封邮件：约 1-3 分钟
- 1000封邮件：约 10-30 分钟
- 更多邮件：可能需要更长时间

程序会实时显示进度和预计剩余时间。

### Q3: 下载中断了怎么办？

**A:** 不用担心！
- 程序支持**断点续传**功能
- 再次运行程序，它会自动跳过已下载的邮件
- 从中断的地方继续下载

### Q4: 会删除服务器上的邮件吗？

**A:** 不会！
- 程序只**读取**邮件，不会修改或删除
- 服务器上的邮件完全不受影响
- 这是一个安全的备份工具

### Q5: 我的密码安全吗？

**A:** 安全措施：
- 密码只在您的电脑上使用
- 不会上传到任何服务器（除了您的邮箱服务器）
- 建议使用授权码而不是真实密码
- 如果不放心，下载后可以在邮箱设置中撤销授权码

### Q6: 支持哪些邮箱？

**A:** 目前支持：
- ✅ 网易企业邮箱（qiye.163.com）
- ❓ 其他邮箱需要修改服务器配置

### Q7: 能下载附件吗？

**A:** 可以！
- 程序会自动下载所有附件
- 附件保存在每封邮件的 `attachments` 文件夹中
- 保持原始文件名和格式

### Q8: 可以选择下载某个时间段的邮件吗？

**A:** 目前版本：
- 可以限制下载数量（如最新100封）
- 可以全部下载
- 暂不支持按日期范围筛选（未来版本会添加）

### Q9: 下载失败怎么办？

**A:** 常见原因和解决方法：

**登录失败：**
- 检查账号密码是否正确
- 尝试使用授权码
- 确认企业邮箱已开启 IMAP 服务

**连接失败：**
- 检查网络连接
- 检查防火墙设置
- 确认不是公司网络限制

**部分邮件下载失败：**
- 这很正常，某些邮件可能有特殊格式
- 程序会跳过失败的邮件，继续下载其他邮件
- 查看统计信息了解成功和失败的数量

### Q10: 下载完成后如何查看邮件？

**A:** 多种方式：

1. **查看纯文本内容**
   - 打开邮件文件夹中的 `content.txt`

2. **查看网页格式**
   - 用浏览器打开 `content.html`

3. **用邮件客户端打开**
   - 双击 `raw_email.eml` 文件
   - 会自动用系统默认邮件客户端打开

4. **查看附件**
   - 进入 `attachments` 文件夹
   - 直接双击打开附件文件

## 🎯 使用建议

### 首次使用建议

1. **先测试少量邮件**
   - 第一次使用时，建议只下载最新10封邮件测试
   - 确认正常后，再下载全部邮件

2. **使用授权码**
   - 比直接使用密码更安全
   - 可以随时撤销

3. **启用断点续传**
   - 强烈建议开启
   - 下载中断后可以继续

### 定期备份建议

1. **定期运行程序**
   - 每周或每月运行一次
   - 自动下载新邮件

2. **保存配置**
   - 程序会记住您的配置
   - 下次使用时可以直接使用

3. **备份下载的邮件**
   - 将下载文件夹复制到移动硬盘
   - 或上传到云盘备份
