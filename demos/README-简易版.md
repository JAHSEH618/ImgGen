# 📧 网易企业邮箱下载工具 - 简易版

**一键下载您的所有邮件到电脑！**

无需编程知识，按照向导操作即可完成！

---

## 🚀 三步开始

### 1️⃣ 双击运行

**Windows:** 双击 `启动邮件下载工具.bat`
**Mac:** 双击 `启动邮件下载工具.command`
**Linux:** 运行 `./启动邮件下载工具.sh`

### 2️⃣ 回答问题

程序会问您几个问题：
- 邮箱账号
- 密码（建议使用授权码）
- 保存位置
- 下载内容（收件箱/已发送/两者都要）

**注意**：选择"同时下载"时，会先下载已发送邮件，再下载收件箱

### 3️⃣ 等待完成

程序会自动下载，实时显示进度！

---

## 📋 准备工作

确保电脑已安装 **Python 3**

- Windows: https://www.python.org/downloads/
- Mac: 通常已自带
- Linux: `sudo apt-get install python3`

---

## 🔐 获取授权码（推荐）

1. 登录网易企业邮箱网页版
2. 设置 → 安全 → 客户端授权密码
3. 生成新授权码
4. 在程序中使用授权码

**为什么要用授权码？**
- 更安全
- 可以随时撤销
- 不会泄露真实密码

---

## ✨ 主要功能

- ✅ 自动下载已发送邮件和收件箱（先下载已发送）
- ✅ 保存邮件正文和所有附件
- ✅ 断点续传（中断后可继续）
- ✅ 实时进度显示
- ✅ 安全只读（不会删除服务器邮件）

---

## 📁 下载的邮件在哪里？

默认位置：`您的用户目录/邮件下载`

每封邮件包含：
- `metadata.json` - 邮件信息
- `raw_email.eml` - 原始邮件（可用邮件客户端打开）
- `content.txt` - 纯文本内容
- `content.html` - 网页格式内容
- `attachments/` - 附件文件夹

文件夹结构：
```
邮件下载/
├── Sent/              # 已发送（优先下载）
│   └── ...
└── INBOX/             # 收件箱
    └── ...
```

## ❓ 常见问题

**Q: 我不懂技术，能用吗？**
A: 当然！只需双击运行，回答几个问题即可。

**Q: 会删除服务器上的邮件吗？**
A: 不会！程序只读取，不会修改或删除。

**Q: 下载中断了怎么办？**
A: 再次运行程序，会自动续传，不会重复下载。

**Q: 下载需要多久？**
A: 约1000封邮件需要10-30分钟，程序会显示进度。

**Q: 密码安全吗？**
A: 密码只在本地使用，建议使用授权码更安全。

## 🔧 故障排除

**如果程序无法启动，出现 "ModuleNotFoundError" 错误：**

1. 运行环境检查脚本：
   ```bash
   python3 检查环境.py
   ```

2. 如果发现文件冲突，删除以下文件（如果存在）：
   - `email.py`（空文件或测试文件）
   - `__pycache__` 目录

3. 清理后重新运行启动脚本

**常见问题：**
- 确保不要在 demos 目录下创建名为 `email.py` 的文件
- 这会与 Python 标准库冲突
