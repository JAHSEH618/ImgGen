# 📧 网易企业邮箱下载工具

**一键下载您的所有邮件到电脑！**

专为非技术人员设计，按照向导操作即可完成！

---

## 🚀 快速开始

### 根据您的操作系统选择：

#### 🍎 Mac 用户
1. 进入 `Mac版` 文件夹
2. 双击运行 `启动邮件下载工具.command`
3. 首次运行：右键点击 → 打开 → 确认

#### 🪟 Windows 用户
1. 进入 `Windows版` 文件夹
2. 双击运行 `启动邮件下载工具.bat`

#### 🐧 Linux 用户
1. 进入 `Linux版` 文件夹
2. 在终端中运行：`./启动邮件下载工具.sh`

### 按照向导回答问题

程序会问您几个简单问题：
1. 邮箱账号
2. 密码/授权码（建议使用授权码）
3. 保存位置
4. 下载内容（收件箱/已发送/两者）

**注意**：选择"同时下载"时，会先下载已发送邮件，再下载收件箱

## 🔐 如何获取授权码

1. 登录网易企业邮箱网页版
2. 设置 → 安全 → 客户端授权密码
3. 生成新授权码
4. 在程序中使用授权码

**为什么要用授权码？**
- 更安全
- 可以随时撤销
- 不会泄露真实密码

- ✅ 自动下载已发送邮件和收件箱（先下载已发送）

## 🔧 故障排除

**如果程序无法启动：**

1. 先运行环境检查：
   ```bash
   python3 检查环境.py
   ```

2. 确保已安装 Python 3.6 或更高版本
   - Windows: https://www.python.org/downloads/
   - Mac: 通常已自带
   - Linux: `sudo apt-get install python3`

3. 查看详细文档中的故障排除章节

## ❓ 常见问题

**Q: 我不懂技术，能用这个工具吗？**
A: 完全可以！只需双击启动文件，回答几个简单问题即可。

**Q: 会删除服务器上的邮件吗？**
A: 不会！程序只读取，不会修改或删除。

**Q: 下载中断了怎么办？**
A: 再次运行程序，会自动续传，不会重复下载。

**Q: 下载需要多久？**
A: 约1000封邮件需要10-30分钟，程序会显示进度。
