# 🍎 Mac 版使用说明

## 快速开始

### 1️⃣ 双击运行
双击 `启动邮件下载工具.command` 文件

### 2️⃣ 首次运行
如果出现安全提示：
1. 右键点击文件
2. 选择"打开"
3. 点击"打开"确认

### 3️⃣ 按照向导操作
程序会问您几个简单问题，回答后自动开始下载

---

## 💡 提示

- 确保已连接网络
- 建议使用授权码而不是密码
- 下载完成后会自动打开文件夹
