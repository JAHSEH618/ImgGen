### 使用说明

现在当您选择"同时下载"时，程序会：
1. 首先连接到邮箱
2. 先下载"已发送"文件夹的所有邮件
3. 然后下载"收件箱"文件夹的所有邮件

**文件夹结构**：
```
邮件下载/
├── Sent/              # 已发送（优先下载）
│   ├── 1_邮件主题1/
│   └── 2_邮件主题2/
└── INBOX/             # 收件箱
    ├── 1_邮件主题1/
    └── 2_邮件主题2/
```

### 为什么这样改？

1. **已发送邮件更重要**：很多时候，您发送出去的邮件（工作交流、重要通知等）比收到的邮件更重要
2. **优先备份**：万一下载中断，至少已经备份了已发送的邮件
3. **符合备份习惯**：很多用户更关心自己发出去的内容

### 兼容性

- ✅ 完全向后兼容
- ✅ 旧的配置文件仍然可用
- ✅ 可以自定义任意顺序

### 如何自定义顺序？

如果您想要其他顺序，可以在配置文件中修改 `folders` 数组：

```json
// 只下载收件箱
"folders": ["INBOX"]

// 只下载已发送
"folders": ["Sent"]

// 先收件箱，后已发送
"folders": ["INBOX", "Sent"]

// 先已发送，后收件箱（默认推荐）
"folders": ["Sent", "INBOX"]

// 自定义多个文件夹
"folders": ["Sent", "INBOX", "Drafts", "Trash"]
```
