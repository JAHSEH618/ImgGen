# 🪟 Windows 版使用说明

## ⚡ 快速开始

### 推荐方式（如遇到问题优先尝试）

1. **双击运行**：`启动邮件下载工具-简化版.bat` ⭐ 推荐
2. **或使用标准版**：`启动邮件下载工具.bat`
3. **按照向导操作**：程序会问您几个简单问题，回答后自动开始下载

### ⚠️ 如果遇到 'n' 命令错误或进入 Python 交互模式

立即尝试：
1. 运行 `启动邮件下载工具-简化版.bat`
2. 或运行 `调试信息.bat` 收集诊断信息
3. 查看 `故障排除指南.md` 的"问题 0"部分

---

## 📋 准备工作

确保已安装 Python 3：
- 下载地址：https://www.python.org/downloads/
- 安装时勾选"Add Python to PATH"

---

## 💡 提示

- 确保已连接网络
- 建议使用授权码而不是密码
- 下载完成后会自动打开文件夹

---

## 🔧 需要帮助？

### 遇到问题？

1. **快速诊断**：双击运行 `检查环境.bat` 或 `调试信息.bat`
2. **使用简化版**：双击运行 `启动邮件下载工具-简化版.bat`
3. **查看故障排除**：打开 `故障排除指南.md` ⭐ 新增
4. **环境检查**：返回上级目录，运行 `检查环境.py`

- `检查环境.bat` - Python 环境诊断工具
- `调试信息.bat` - 详细调试信息收集工具 ⭐ 新增
- `故障排除指南.md` - 详细的问题解决方案 ⭐ 新增

## ⚠️ 常见问题速查

### 问题 1: 'python' 不是内部或外部命令

**解决方法**：
1. 下载并安装 Python：https://www.python.org/downloads/
2. ⚠️ 安装时务必勾选 **"Add Python to PATH"**
3. 安装完成后重启命令提示符
4. 或运行 `检查环境.bat` 进行诊断

### 问题 2: 'n' 不是内部或外部命令 + Python 进入交互模式

**解决方法**：
1. 使用 `启动邮件下载工具-简化版.bat` 代替标准版
2. 运行 `调试信息.bat` 收集诊断信息
3. 查看 `故障排除指南.md` 的"问题 0"获取详细解决方案

### 问题 3: 其他错误

请查看 `故障排除指南.md`，里面包含了所有常见问题的详细解决方案。
