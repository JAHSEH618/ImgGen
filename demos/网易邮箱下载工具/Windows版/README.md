## 📋 准备工作

确保已安装 Python 3：
- 下载地址：https://www.python.org/downloads/
- 安装时勾选"Add Python to PATH"

## 💡 提示

- 确保已连接网络
- 建议使用授权码而不是密码
- 下载完成后会自动打开文件夹

## ⚠️ 常见问题

如果出现以下错误：
```
'python' 不是内部或外部命令
```

**解决方法**：
1. 下载并安装 Python：https://www.python.org/downloads/
2. ⚠️ 安装时务必勾选 **"Add Python to PATH"**
3. 安装完成后重启命令提示符
4. 或运行 `检查环境.bat` 进行诊断

更多问题请查看 `故障排除指南.md`
