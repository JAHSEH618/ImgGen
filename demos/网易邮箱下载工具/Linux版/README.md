# 🐧 Linux 版使用说明

## 快速开始

### 1️⃣ 打开终端
在当前目录打开终端

### 2️⃣ 运行脚本
```bash
./启动邮件下载工具.sh
```

### 3️⃣ 按照向导操作
程序会问您几个简单问题，回答后自动开始下载

---

## 📋 准备工作

确保已安装 Python 3：

**Ubuntu/Debian:**
```bash
sudo apt-get install python3
```

**CentOS/RHEL:**
```bash
sudo yum install python3
```

**Fedora:**
```bash
sudo dnf install python3
```

---

## 💡 提示

- 确保已连接网络
- 建议使用授权码而不是密码
- 脚本已设置可执行权限
